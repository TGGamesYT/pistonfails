# Piston Fails
This is a client-side Minecraft mod for 26.3 fabric that visualizes what and how many blocks a piston failed to move.

### Features
- when a piston tries to push over 12 blocks but cant, a highlight appears on the blocks, with their count
- unpushable blocks appear red
- right clicking a piston with an empty hand shows the highlight that whould be moved when activated
- right clicking any block while a piston is in the hand shows the highlight of what whould happen if a piston pushed thoose blocks in the direction you are facing
- modifying a highlighted area while still highlighted updates the highlight
